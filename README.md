# Joshika G. — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript, ready for GitHub Pages.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your professional email.
2. Replace the LinkedIn link `https://www.linkedin.com/` with your actual profile URL.
3. Review the skills, project descriptions, and training details so they accurately reflect your experience. Add links to any additional repositories or certificates you want to share.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a **new public repository** named `joshikaguna.github.io` if your GitHub username is `joshikaguna`. If you prefer a repository named `portfolio`, the site URL will be `https://joshikaguna.github.io/portfolio/` instead.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root (not inside an extra nested folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**; select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait a few minutes, refresh the Pages screen, and open the published URL shown there.

## Run locally
Open `index.html` in a browser. No build tools are required.
